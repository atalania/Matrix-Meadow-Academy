📖 Before You Start You Should Know
Matrix multiplication combines two transformations into one result matrix. Think in terms of ROWS and COLUMNS: • Pick one row from A. • Pick one column from B. • Multiply matching positions, then add. • That sum becomes one cell in C. Compatibility rule: (# columns in A) must equal (# rows in B) Example: (2×3) × (3×4) works and gives a (2×4) matrix. 2×2 walkthrough: A = [1 2] B = [5 6] [3 4] [7 8] C[0][0] = (1×5) + (2×7) = 19 C[0][1] = (1×6) + (2×8) = 22 C[1][0] = (3×5) + (4×7) = 43 C[1][1] = (3×6) + (4×8) = 50 So: C = [19 22] [43 50] Important: order matters. Usually A×B ≠ B×A, so keep matrix order exactly as shown in the prompt. Beginner workflow for each drill: 1) Solve one cell at a time (top-left to bottom-right). 2) Write each mini expression before simplifying. 3) Re-check signs on negative numbers. 4) Use Check to inspect dot-product breakdowns and learn from mistakes.

📐 The Formula
C[i][j] = Σ A[i][k] × B[k][j] Each entry of C is the dot product of a ROW of A with a COLUMN of B. 2×2 example: C[0][0] = A[0][0]·B[0][0] + A[0][1]·B[1][0] C[0][1] = A[0][0]·B[0][1] + A[0][1]·B[1][1] C[1][0] = A[1][0]·B[0][0] + A[1][1]·B[1][0] C[1][1] = A[1][0]·B[0][1] + A[1][1]·B[1][1]
